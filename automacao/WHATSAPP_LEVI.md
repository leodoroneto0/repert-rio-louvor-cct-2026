# Como abrir a conversa do Levi no WhatsApp (tarefas agendadas: lembretes e música teste)

Regra do Neto (13/11/2026): as TAREFAS AGENDADAS usam o WhatsApp Web no Chrome (roda sozinho, sem aprovação). O aplicativo WhatsApp Desktop (uso do computador) só é usado quando o Neto pede na conversa, porque ele exige aprovação a cada sessão; nesse caso, confira o número do Levi em "Dados do contato" (há dois contatos "Levi"; o certo é +55 16 99744-4381) e FECHE o app ao terminar.

- O WhatsApp Web NÃO funciona no navegador embutido do app. Use o Chrome do Neto pela extensão Claude in Chrome: carregue numa única chamada do ToolSearch "select:mcp__claude-in-chrome__tabs_context_mcp,mcp__claude-in-chrome__list_connected_browsers,mcp__claude-in-chrome__select_browser,mcp__claude-in-chrome__navigate,mcp__claude-in-chrome__computer,mcp__claude-in-chrome__find,mcp__claude-in-chrome__javascript_tool,mcp__claude-in-chrome__tabs_create_mcp,mcp__claude-in-chrome__tabs_close_mcp".
- Chame tabs_context_mcp com createIfEmpty true. Se disser que a extensão não está conectada, chame list_connected_browsers: se houver exatamente um navegador, chame select_browser com o deviceId dele e repita tabs_context_mcp; se houver nenhum (Chrome fechado) ou mais de um, o WhatsApp não está acessível agora (a tarefa diz o que fazer).
- Crie uma aba nova (tabs_create_mcp) e navegue para https://web.whatsapp.com/send?phone=5516997444381 (contato "Levi", +55 16 99744-4381). Espere carregar (até ~30 s).
- Se aparecer o QR code ("Escaneie para entrar"), o WhatsApp Web deslogou: não faça nada nele, feche a aba e avise o Neto pelo bot ("o WhatsApp Web deslogou; abra web.whatsapp.com no Chrome e escaneie o QR").
- Confira o cabeçalho da conversa (document.querySelector('#main header').innerText): tem que ser o contato "Levi". Se aparecer outro nome, um grupo ou aviso de número inválido, não faça nada e avise o Neto.
- Mensagens: .message-out = enviadas pelo Neto; .message-in = recebidas do Levi (o horário fica no atributo data-pre-plain-text, ex.: "[16:28, 10/11/2026] Levi: ").
- Para escrever: clique na caixa "Digite uma mensagem"/"Type a message", Shift+Enter quebra a linha (duas vezes = linha em branco entre parágrafos), Enter só no fim para enviar. Antes do Enter, confira o texto com um screenshot; depois, confira que a mensagem apareceu (último .message-out).
- No WhatsApp, só abra a conversa do Levi; não leia nem mexa em outras conversas. Ao terminar, FECHE a aba (tabs_close_mcp). O login fica salvo no Chrome.
