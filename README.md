# Repertório do Louvor CCT 2026

Página pública do repertório do Ministério de Louvor da Comunidade Cristã de Taquaritinga.

- `index.html`: a página publicada pelo GitHub Pages (gerada automaticamente).
- `dados/`: os dados da página (repertório base, tons, registros dos cultos e grafias unificadas).
- `automacao/`: o modelo da página e o script que acrescenta cultos novos à planilha e aos dados.
